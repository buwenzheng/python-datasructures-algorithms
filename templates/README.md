# 算法框架模板

这里存放你**亲手总结**的算法框架模板。

## 使用方式

学完一个算法章节后，在此目录创建对应的模板文件。
模板是你自己推导出来的，不是抄来的 —— 这样才能真正掌握。

### 创建流程

```
1. 学完「滑动窗口」章节
2. 在这里创建 sliding_window.py，写出你的模板
3. 对比 labuladong 给的模板，查漏补缺
4. 以后刷题时直接 import 你的模板
```
