## 一句话概括

算法的本质是穷举，框架思维就是让穷举做到「不遗漏、不冗余」。

## 核心要点

<!-- 用自己的话拆解成几个关键点，每个关键点配一句话解释。不抄原文，用自己的语言重组。 -->

### 要点 1：算法 = 穷举

> 所有的算法题，本质上都在做一件事：穷举所有可能，找出答案。

穷举要解决两个问题：
- **无遗漏**：所有可能都试过 → 靠算法框架保证
- **无冗余**：不做无用功 → 靠剪枝/备忘录/动态规划

### 要点 2：数据结构是容器，算法是方法

| 数据结构 | 存储方式 | 对应算法操作 |
|---------|---------|-------------|
| 数组 | 连续内存 | 索引访问、双指针 |
| 链表 | 离散节点 + 指针 | 遍历、快慢指针 |
| 树 | 层级 + 指针 | 递归遍历（前/中/后序） |
| 图 | 节点 + 边 | BFS / DFS |

### 要点 3：框架的复用性

> 学会一个框架 = 会解一类题。框架之间会组合复用。

```
数组遍历框架 → 双指针框架 → 滑动窗口框架
树遍历框架 → DFS 框架 → 回溯框架
树遍历框架 → 分解问题 → 动态规划框架
```

## 类比理解

<!-- 用生活中的类比解释抽象概念。好的类比能让概念一次记住。 -->

| 概念 | 类比 |
|------|------|
| 穷举 | 开密码锁：一位一位试所有组合 |
| 无遗漏 | 试锁时 000-999 每个都试到，不跳号 |
| 无冗余 | 已经试过 123 就不会再试 321（剪枝） |
| 框架 | 万能钥匙模板：不同锁换芯，开锁手势不变 |
