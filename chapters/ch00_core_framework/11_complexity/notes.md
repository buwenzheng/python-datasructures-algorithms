## 核心要点

<!-- 用自己的话拆解成几个关键点，每个关键点配一句话解释。 -->

### 要点 1：大 O 表示法

> 大 O 描述的是增长趋势，不是精确时间。O(n) 意味着输入翻倍，时间大约也翻倍。

常见复杂度从快到慢：

```
O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)
```

### 要点 2：时间复杂度怎么算

| 代码结构 | 复杂度 | 例子 |
|---------|--------|------|
| 单层循环 | O(n) | 遍历数组 |
| 嵌套循环 | O(n²) | 冒泡排序 |
| 每次折半 | O(log n) | 二分查找 |
| 递归分治 | O(n log n) | 归并排序 |
| 递归全排列 | O(n!) | 回溯枚举 |

### 要点 3：空间复杂度

> 额外开了多少内存。原地操作是 O(1)，开了等长数组是 O(n)。

常见情况：
- O(1)：原地交换、指针移动
- O(n)：额外数组、哈希表
- O(log n)：递归调用栈（二分）
- O(n)：递归调用栈（线性递归）

## 类比理解

| 概念 | 类比 |
|------|------|
| 大 O | 买车看「油耗趋势」：不关心具体几升，关心高速上跑 100km vs 1000km 油耗翻几倍 |
| O(1) | 电梯按楼层：不管 1 楼还是 100 楼，按一下就到，时间一样 |
| O(log n) | 翻字典：从中间劈开，每次排除一半，很快定位 |
| O(n) | 排队点名：100 人就要叫 100 次 |
| O(n²) | 握手问题：n 个人两两握手，次数 ≈ n²/2 |
| O(2ⁿ) | 细胞分裂：每代翻倍，指数爆炸 |

## 对比与区分

| 维度 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 衡量什么 | 运算次数随输入增长 | 内存占用随输入增长 |
| 优先级 | 通常优先优化 | 可用空间换时间（如哈希表） |
| 最坏情况 | 大 O 默认就是最坏 | 同上 |

| 概念 | 大 O（最坏） | Ω（最好） | θ（精确） |
|------|-----------|----------|----------|
| 用途 | 工程默认关心 | 理论分析 | 学术精确 |
| 实际 | 面试和刷题只看大 O | 几乎不用 | 几乎不用 |
